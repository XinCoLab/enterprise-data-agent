# 知识卡片编辑

分支：`feat/knowledge-workspace-ui`；基于 `50baf60`。

## 修正后的设计范围

参考图只用于右侧详情卡片，不用于重做整个应用。撤回上一版对全局配色、导航尺寸、图标和图谱外观的修改；`frontend/app/globals.css` 内容恢复至基线版本。

- 点击已有节点：右侧打开详情；点击“编辑”进入编辑状态。
- 点击“新增”：画布上弹出独立编辑窗口，可拖动标题栏，也可聚焦标题栏后用方向键移动。右侧详情不被替换。
- 卡片显示名称、别名、定义、关联、生效数据源、来源；底部保留版本和编辑入口。
- 长定义通过“完整定义”展开，默认显示知识自身的摘要，不改写原始内容。
- 添加关联使用卡片内表单；保存后持久化 YAML 并重载知识。
- 路径、ZIP 导入和统计放入知识库设置。
- 不替换框架，不修改 Agent 执行流程，不创建数据库表或伪造外键验证。
